# ตั้งค่าให้ไฟล์ที่นักเรียนส่งเก็บเข้า Google Drive อัตโนมัติ (ใช้ครั้งเดียว ~5 นาที)

1. เปิด [sheets.google.com](https://sheets.google.com) → สร้างสเปรดชีตใหม่ ตั้งชื่ออะไรก็ได้ เช่น "ไฟล์งานนักเรียน"
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจากไฟล์ `apps-script/Code.gs` ในโปรเจกต์นี้ลงไปแทน
4. กด **บันทึก** (ไอคอนแผ่นดิสก์)
5. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
   - ประเภท: เลือก **เว็บแอป (Web app)**
   - Execute as: **Me (บัญชีของฉัน)**
   - Who has access: **Anyone (ทุกคน)**
   - กด **Deploy**
6. ครั้งแรกจะมีหน้าต่างขอสิทธิ์ (Authorize access) — เลือกบัญชี Google ของอาจารย์ แล้วกด "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → Allow (ปลอดภัย เพราะเป็นสคริปต์ที่อาจารย์เพิ่งสร้างเอง — ต้องขอสิทธิ์ Drive ด้วยเพราะสคริปต์นี้ต้องเซฟไฟล์ลง Drive ของอาจารย์)
7. คัดลอกลิงก์ **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
8. เปิดไฟล์ `js/config.js` ในโปรเจกต์นี้ วาง URL นั้นลงใน `API_URL`
9. อัปโหลด/push โค้ดขึ้นเว็บอีกครั้ง (หรือแจ้งให้ผู้ดูแลเว็บอัปเดตให้)

หลังจากนี้ไฟล์ที่นักเรียนส่งจะถูกเก็บไว้ใน Google Drive ของอาจารย์ ในโฟลเดอร์ชื่อ "ไฟล์งานนักเรียน (ส่งผ่านเว็บ)" แยกเป็นโฟลเดอร์ย่อยตามวิชา → ห้องเรียน โดยอัตโนมัติ (สร้างโฟลเดอร์ให้เองครั้งแรกที่มีคนส่งงาน) และบันทึกรายการ/คะแนน/คอมเมนต์ไว้ในชีต "Submissions"

## รหัสผ่านหน้าอาจารย์ (ตั้งคะแนน)

หน้าอาจารย์ต้องใส่รหัสผ่านก่อนให้คะแนนได้ ค่าเริ่มต้นคือ `1234` — แนะนำให้เปลี่ยนเป็นรหัสของตัวเอง:

1. ใน Apps Script เปิดเมนู **Project Settings** (รูปเฟือง) → เลื่อนลงมาที่ **Script Properties**
2. กด **Add script property** → Property = `ADMIN_PASSCODE`, Value = รหัสที่ต้องการ → Save

ถ้าไม่ตั้งค่านี้ ระบบจะใช้รหัสเริ่มต้น `1234` ไปก่อน
